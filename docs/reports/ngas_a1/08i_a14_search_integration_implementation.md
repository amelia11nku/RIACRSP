# NGAS-A1.4 搜索集成实现与预注册设计

## 实现结论

A1.4 已实现为单一路径的联合动作搜索器。冻结 C1 critic 在一次刷新中编码当前 CSG，并批量评分该状态下由三种破坏尺度、完整去重目标库和五种修复算子组成的联合动作库。评分被转换为带显式均匀混合下限的概率分布，并缓存到后续搜索迭代；搜索过程不进行任何在线神经训练。

在线组合器与神经先验相互独立。它分别维护破坏尺度、目标家族、修复算子、尺度×修复和家族×修复的分段统计，只在固定段边界更新。反馈明确区分拒绝、接受但更差或持平、改善当前解、新全局最优四类结果，并使用归一化改善幅度和分层奖励。

## 六组冻结消融

1. `NEURAL_PRIOR_ONLY`：初始 C1 先验持续影响搜索，不启用在线组合器。
2. `ONLINE_PORTFOLIO_ONLY`：不调用 critic，使用独立在线组合器及固定动作库刷新。
3. `NEURAL_X_PORTFOLIO`：初始 C1 先验与在线组合器相乘，先验不刷新。
4. `ONE_SHOT_TOP1`：只在第一次迭代执行初始先验 top-1，后续均匀采样。
5. `PERSISTENT_FIXED_REFRESH`：C1 先验与在线组合器持续作用，每 20 次迭代刷新。
6. `PERSISTENT_EVENT_REFRESH`：C1 先验与在线组合器持续作用，由搜索事件刷新。

事件刷新覆盖新全局最优、有意义的当前解改善、关键结构变化、主导瓶颈变化、停滞、连续高先验失败、最大先验年龄和搜索阶段变化。所有事件受 5 次迭代的最小刷新间隔约束；因间隔被抑制的阶段变化会保留到下一次可刷新时。

## 随机性和遥测

候选库、神经先验采样、在线探索、修复构造、接受判定和诊断使用独立的稳定哈希 RNG 命名空间。修复和接受的键不包含消融模式，因此在相同实例、种子、迭代与动作下使用相同下游随机数。

遥测分别记录 CSG/关键结构、动作库、特征、张量传输、模型前向、采样、修复、解码、接受和结构监控时间。0.10、0.25、0.50、0.75 检查点遵守因果归属；1.0 点记录真实终止时间、评估数和最终 incumbent。每次刷新保留原因、先验年龄、分布熵、有效动作数、相对均匀分布的总变差和 top-5 动作。

## 小规模 R12 开发边界

预注册配置为 `configs/ngas_a1_search_integration_v1.json`。子集固定为三个实例和三个种子，覆盖 S/M/L、CF1/CF2/CF3 和 C01/C02；六种模式共 54 次运行。每个实例—种子块内所有模式使用相同的 `0.5 × |O|` 秒上限，即完整 R12 `2 × |O|` 上限的四分之一。模型加载不计入预算，初始化、刷新、搜索、修复和解码全部计入。

只有 `PERSISTENT_FIXED_REFRESH` 和 `PERSISTENT_EVENT_REFRESH` 可成为生产机制候选。两者必须达到 9/9 可行回放、critic 影响中位数不低于 0.8、每次 critic 调用引导迭代中位数不低于 4，并满足预注册的最终质量或 anytime AUC 可信规则。若均不合格，终态固定为 `NGAS_A1_REVISE_SEARCH_INTEGRATION`，A1.5 保持锁定。

机制冻结后必须执行种子匹配、fold-0 匹配的 C1/R1 解释性求解器消融。R1 的生产资格不会因该消融结果改变。A1.5 只有在该比较和 A1.4 完成审计后才可解锁。
