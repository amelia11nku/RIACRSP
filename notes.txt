RCIAS implementation and experiment notes

Purpose
-------
Maintain a reproducible RCIAS-2.0 chain from frozen public instances through a
deterministic decoder, independent feasibility audit, exact Tiny enumeration,
normalized graph/candidate interfaces, RT-HGT, and Behavior Cloning rollout.

Runs
----
1. python -m compileall .
2. pytest -q
3. python scripts/generate_canonical_benchmarks.py --verify-only
4. python scripts/run_small_validation.py
5. python scripts/profile_graph_builder.py
6. python scripts/run_bc_validation.py
7. python scripts/audit_repo_structure.py

Machine-readable results are stored below outputs/validation,
outputs/profiling, and outputs/bc_validation. Phase reports are under
docs/reports; implementation_validation_report.md records the earlier decoder
foundation and is superseded by the Phase 2 final report for current paths.
